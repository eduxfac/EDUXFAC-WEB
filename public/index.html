Actualizar SOLO stock desde Excel

Una fila por producto. Complete solo Stock físico (vacío = omitir). Faltantes: se descuentan de los lotes reales más antiguos. Sobrantes: se agregan al último lote real de esta sucursal. Sin lote real: se ajusta el stock sin lote, sin inventar número ni vencimiento. Si hay errores, no se importa ninguna fila.
Use el archivo descargado para esta sucursal. Solo edite Stock físico, en unidades base y hasta 3 decimales. El reporte detallado por lotes no se usa para este conteo.

Importación inicial de inventario desde Excel

Una fila por lote. Repita código interno y datos maestros iguales para cada producto. Revise los errores antes de confirmar.
